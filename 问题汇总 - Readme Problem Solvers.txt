1. 系统将 Python 的 `.py` 或 `.pyw` 文件错误地关联到其他程序（例如 3ds Max）时，请运行脚本目录中的 BAT 文件修复文件关联：

   `一定要先点我安装Python  - Click to Install Python First.bat`

   该脚本会将 `.py` 和 `.pyw` 绑定到经过验证的 PC-REHD Python 运行时，并在写入后回读验证注册表设置。

   If Windows opens Python `.py` or `.pyw` files with the wrong application (for example, 3ds Max), run the BAT file in the Script Folder to repair the file association.

   The script binds `.py` and `.pyw` to the verified PC-REHD Python runtime for the current Windows user and verifies the registry settings after writing them.
