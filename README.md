# PC-REHD Code X

PC-REHD Code X is a Windows desktop workflow tool for Resident Evil 6 / PC-REHD `.MOD`, `.MRL`, and FBX round-trip work with 3ds Max and Blender.

This repository is the source and dependency snapshot for the current Code X release. The ready-to-run package is provided from the GitHub Releases page as a separate archive.

## Scope

- Python Launcher and the Python export/import bridge.
- 3ds Max and Blender agent/FBX workflow code.
- Texture, material, MRL, mesh, normal, and skeletal-edit support code.
- The pinned dependency snapshot in `PY依赖 PY Libs`.
- Windows bootstrap scripts and the Python installer used by the distribution.

The repository intentionally excludes the embedded Python runtime, generated bytecode, diagnostic output, V4 backups, game files, user models, and private scene data.

## Installation

1. Open the repository's **Releases** page.
2. Download `RE6 PC-REHD CODE X版.7z`.
3. Extract the archive to a writable folder with a short path.
4. Run `先点Bat文件 - Click Bat First.ps1`, or run `一定要先点我安装Python - Click to Install Python First.bat` first when Python has not been installed.
5. Back up your `.MOD`, `.MRL`, FBX, and DCC scenes before using import, export, or skeletal-edit operations.

## Important Notes

- This is an unofficial community tool. It is not affiliated with or endorsed by CAPCOM.
- The repository and Release assets contain no Resident Evil 6 game assets.
- The tool can modify scenes and generate `.MOD` files. Validate generated files with backups and your own game-testing workflow.
- Blender and 3ds Max are separate modes with separate agents and state. Do not treat a Blender import without hierarchy repair as a round-trip validation result.

## Source Layout

| Path | Purpose |
| --- | --- |
| `PC-REHD Code X Launcher.py` | Main Windows Launcher, UI, agent orchestration, and tool routing. |
| `codex_python_export_bridge.py` | Export bridge and `.MOD` writer path. |
| `codex_re6_mod_import_fbx.py` | `.MOD` to FBX / import preparation path. |
| `codex_fbx_probe.py` | FBX inspection and contract probing. |

| `PY依赖 PY Libs/` | Pinned Python dependencies and source/vendor snapshots. |
| `先点Bat文件 - Click Bat First.ps1` | Bootstrap and environment validation entry point. |
